# 2.1 线性模型

## 1、代码见2.1线性模型.py

## 2、模型结构

```
LinearRegressionModel(
  (linear): Linear(in_features=10, out_features=1, bias=True)
)
```

说明：

- 输入维度为10，即10个特征值

- 输出维度为1，即一个目标值

- 有偏置项b

- 即
  $$
  y=xW 
  T
   +b
  $$

## 3、最终测试结果及评价指标

```
Epoch [500/2000], Loss: 95.3391
Epoch [1000/2000], Loss: 39.7845
Epoch [1500/2000], Loss: 15.9766
Epoch [2000/2000], Loss: 8.2760

========== 测试集评价指标 ==========
MSE  : 8.2405

MAE  : 2.3153
R²   : 0.6389

========== 训练集评价指标 ==========
MSE  : 8.2690
R²   : 0.6562
```

评价指标解释：

- MSE：均方误差，衡量预测值与真实值平方误差的平均值，越小越好。
- RMSE：均方根误差，约 3.81。
- MAE：平均绝对误差，约 3.02。
- R²：决定系数，越接近 1 越好。约 0.42，说明线性模型只能解释目标变量约 42% 的方差。

## 5、简要分析

`make_friedman1` 生成的目标函数：
$$

y = 10 \sin(\pi x_0 x_1) + 20 (x_2 - 0.5)^2 + 10 x_3 + 5 x_4 + \epsilon
$$
但线性模型只能学习线性项，无法表达目标函数中的正弦、平方，因此，模型勉强拟合函数线性部分，其他拟合不了，故R² 只有约 0.42，MSE 约 14.5，预测效果有限。

结论：对于非线性数据，单纯使用线性模型会导致明显的欠拟合。若要提升效果，需要引入非线性模型，或者使用带隐藏层和激活函数的神经网络。
