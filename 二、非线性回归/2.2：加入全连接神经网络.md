# 2.2：加入全连接神经网络

## 1、代码及模型结构

代码见MLP.py

MLP模型：

```
MLPModel(
  (net): Sequential(
    (0): Linear(in_features=10, out_features=64, bias=True)
    (1): ReLU()
    (2): Linear(in_features=64, out_features=32, bias=True)
    (3): ReLU()
    (4): Linear(in_features=32, out_features=1, bias=True)
  )
)
```

- 输入维度：10
- 隐藏层 1：64 个神经元，ReLU 激活
- 隐藏层 2：32 个神经元，ReLU 激活
- 输出维度：1

## 5、对两个模型差异的理解

### 拟合能力差异

线性模型只能拟合线性部分，而MLP通过隐藏层和 ReLU 激活，能够逼近非线性函数。

### 参数量的差异

线性模型只有11个参数，表达能力有限。MLP参数更多，能拟合更复杂的函数。

### 训练过程差异

线性模型损失下降快，很快停滞，导致欠拟合。MLP损失下降慢，但最终能到更低水平。
